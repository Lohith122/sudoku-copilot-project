# GitHub Copilot Instructions

## Code Standards
- Write modular, PEP 8-compliant Python code with type hints and docstrings.
- Separate Flask web routing from core Sudoku game logic.
- Ensure all functions include proper error handling.

## Frontend Requirements
- Semantic HTML5, accessible CSS, and modern vanilla JavaScript.
- 9x9 CSS grid with visually distinct alternating 3x3 blocks.
- Full support for mobile and desktop screens.
- Light and dark theme toggle using CSS variables.
- Save top 10 fastest times in browser localStorage.
